## 🔵 Simple Definition (English)
A PDF generator turns data (customer, items, totals) into a fixed-layout PDF file in code, usually in memory, and returns the bytes to be downloaded or emailed.

## 🔵 सरल परिभाषा (Hindi)
PDF generator data (customer, items, totals) को code से एक fixed-layout PDF file में बदलता है, आमतौर पर memory में, और bytes लौटाता है जिन्हें download या email किया जा सके।

---

## 🔴 Problem it Solves
Invoices, receipts and reports must look identical on every device and be printable and legally storable. Hand-building PDFs is painful; libraries handle fonts, tables and pagination.

## 🔴 यह क्यों बना? (Hindi)
Invoice, receipt और reports हर device पर एक जैसे दिखने चाहिए, print हो सकें और कानूनी रूप से सहेजे जा सकें। PDF हाथ से बनाना कठिन है; libraries fonts, tables और pagination संभालती हैं।

## 🟢 How it Works — Step by Step

```
Step 1 → Gather data (items, qty, price) and compute subtotal + GST
Step 2 → Create io.BytesIO() buffer (no temp file)
Step 3 → SimpleDocTemplate(buffer) + "flowables": Paragraph, Table, Spacer
Step 4 → doc.build([...]) lays out and writes PDF bytes into the buffer
Step 5 → buffer.getvalue() -> bytes starting with %PDF-
Step 6 → Return Response(bytes, media_type="application/pdf") or attach to email
```

## 🟢 कैसे काम करता है? (Hindi)
```
Step 1 → Data (items, qty, price) लो और subtotal + GST निकालो
Step 2 → io.BytesIO() buffer बनाओ (temp file नहीं)
Step 3 → SimpleDocTemplate(buffer) और "flowables": Paragraph, Table, Spacer
Step 4 → doc.build([...]) layout करके PDF bytes buffer में लिखता है
Step 5 → buffer.getvalue() -> bytes जो %PDF- से शुरू होते हैं
Step 6 → Response(bytes, media_type="application/pdf") लौटाओ या email में जोड़ो
```

## 💻 Code Example — Basic
```python
# Smallest possible PDF with reportlab (pip install reportlab)
import io  # in-memory buffer
from reportlab.pdfgen import canvas  # low-level drawing API

buf = io.BytesIO()  # memory file
c = canvas.Canvas(buf)  # drawing surface
c.drawString(72, 750, "Hello PDF")  # x=72pt, y=750pt from bottom-left
c.save()  # finish the file
data: bytes = buf.getvalue()  # raw PDF bytes
print(data[:5], len(data) > 500)  # PDFs start with %PDF-
# Output: b'%PDF-' True
```

## 💻 Code Example — Advanced
```python
# Excerpt from main.py: table-based invoice with totals, served by FastAPI
def build_invoice(number: str, customer: str, items: list[Item], gst_rate: float = 0.18) -> bytes:
    buf = io.BytesIO()
    doc = SimpleDocTemplate(buf, pagesize=A4, title=f"Invoice {number}")
    styles = getSampleStyleSheet()
    subtotal = sum(i.qty * i.price for i in items)
    gst = round(subtotal * gst_rate, 2)
    rows = [["Item", "Qty", "Price", "Amount"]]
    rows += [[i.name, i.qty, f"{i.price:.2f}", f"{i.qty * i.price:.2f}"] for i in items]
    rows += [["", "", "Subtotal", f"{subtotal:.2f}"], ["", "", "GST 18%", f"{gst:.2f}"],
             ["", "", "Total", f"{subtotal + gst:.2f}"]]
    table = Table(rows, colWidths=[200, 50, 80, 80])
    doc.build([Paragraph(f"Invoice {number}", styles["Title"]), Spacer(1, 12), table])
    return buf.getvalue()
```
Real output of `python main.py` (reportlab, Python 3.13.3):
```

all ok
```

## 🟠 FastAPI Connection
Return a `Response` with bytes and a `Content-Disposition` header. PDF generation is CPU-bound and blocking, so use a plain `def` route (runs in the threadpool) or push it to a worker; for large files use `StreamingResponse`.

```python
@app.get("/invoice/{number}")
def invoice(number: str) -> Response:  # sync def: runs in a threadpool
    return Response(build_invoice(number, "Asha", []), media_type="application/pdf",
                    headers={"Content-Disposition": f'attachment; filename="invoice-{number}.pdf"'})
```

## ⚠️ Common Mistakes to Avoid
❌ Mistake 1: Writing to a temp file path and forgetting to delete it, or collisions between users.
✅ Correct: `io.BytesIO` in memory.

❌ Mistake 2: Using float for money.
✅ Correct: `Decimal` or integer paise.

```python
# Wrong
0.1 + 0.2      # 0.30000000000000004
# Right
from decimal import Decimal
Decimal("0.1") + Decimal("0.2")   # Decimal('0.3')
```

❌ Mistake 3: Default fonts cannot draw Hindi/Devanagari; text shows as boxes.
✅ Correct: register a TTF font (e.g. Noto Sans Devanagari) with `pdfmetrics.registerFont`. (Not run here.)

## 🧠 Tricky Interview Question
```python
buf = io.BytesIO()
doc.build(story)
print(len(buf.read()))
```
Answer: `0`. After writing, the buffer position is at the end, so `read()` returns nothing. Use `buf.getvalue()` or `buf.seek(0)` first.

## ⚫ Interview Questions + Answers

Q1: reportlab vs WeasyPrint?
A1: reportlab gives precise programmatic layout; WeasyPrint converts HTML/CSS so designers can own the template.

Q2: Why generate in a background job?
A2: Big reports are slow and CPU heavy; run in a worker and notify/download later.

Q3: How do you serve a large PDF?
A3: `StreamingResponse` or object storage (S3) with a pre-signed URL.

Q4: How to test PDF output?
A4: Check header `%PDF-`, extract text with `pypdf`, or snapshot-compare rendered pages.

Q5: What is Content-Disposition?
A5: Header telling the browser to download (`attachment`) or show inline, and the filename.
