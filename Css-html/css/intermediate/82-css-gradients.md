# 82. CSS Gradients (linear, radial)
# हिंदी में: CSS Gradients — Colours का Smooth Mix

---

## 🔵 Simple Definition (English)
A CSS gradient is an image generated by the browser that smoothly blends two or more colours. The main types are `linear-gradient()` (along a line), `radial-gradient()` (from a centre point outwards) and `conic-gradient()` (around a centre, like a pie). Gradients are used as `background` / `background-image` values.

## 🔵 सरल परिभाषा (Hindi)
CSS gradient एक image है जो browser खुद बनाता है और दो या ज़्यादा colours को smoothly मिलाती है। मुख्य types: `linear-gradient()` (एक line के साथ), `radial-gradient()` (centre से बाहर की ओर) और `conic-gradient()` (centre के चारों ओर, pie जैसा)। इन्हें `background` / `background-image` में use करते हैं।

---

## 🔴 Problem it Solves
```
BEFORE:
  - Gradient backgrounds = slicing a 1px-wide PNG and repeating it
  - Extra HTTP request, fixed size, fixed colours, blurry at different DPIs
  - Changing the colours meant opening Photoshop

AFTER:
  .hero { background: linear-gradient(135deg, #f7971e, #ffd200); }
  /* Zero requests, resolution independent, colours editable, animatable via variables */
```

## 🔴 यह क्यों बना? (Hindi)
```
पहले:
  - Gradient के लिए 1px की PNG काटकर repeat करते थे
  - Extra HTTP request, fixed size, अलग screens पर blur
  - Colour बदलना हो तो Photoshop खोलना पड़ता था

अब:
  सिर्फ CSS की एक line, कोई request नहीं, किसी भी size पर sharp, colours आसानी से बदलते हैं।
```

## 🟢 How it Works — Step by Step

```
LINEAR GRADIENT:
  linear-gradient(direction, color-stop1, color-stop2, ...)

  direction:  to right | to bottom right | 135deg
              0deg = to top, 90deg = to right, 180deg = to bottom (default), 270deg = to left
  stops:      colour + optional position   red 0%, blue 100%
  Example:    linear-gradient(90deg, #ff5a5f 0%, #f5a623 100%)

HARD STOPS (no blending): two stops at the same position
  linear-gradient(90deg, red 50%, blue 50%)        -> half red, half blue
  Stripes:  repeating-linear-gradient(45deg, #eee 0 10px, #fff 10px 20px)

RADIAL GRADIENT:
  radial-gradient(shape size at position, stops...)
  radial-gradient(circle at 30% 20%, #fff 0%, #ff5a5f 60%, #800 100%)
  shape: circle | ellipse (default)
  size:  closest-side | farthest-corner (default) | explicit length

CONIC GRADIENT: (Chrome 69+, Safari 12.1+, Firefox 83+)
  conic-gradient(from 0deg at 50% 50%, red, yellow, green, red)
  Pie charts:  conic-gradient(#ff5a5f 0 40%, #1a73e8 0 70%, #34a853 0)

MULTIPLE BACKGROUNDS: comma separated, first is on TOP
  background: linear-gradient(rgba(0,0,0,.5), rgba(0,0,0,.5)), url(hero.jpg);   /* dark overlay on an image */

COLOUR MIDPOINT HINT: a bare percentage between stops shifts where the 50% blend happens
  linear-gradient(red, 20%, blue)

TRANSPARENCY: use `transparent` or rgba with 0 alpha.
  Tip: `transparent` blends toward transparent black in old browsers; modern browsers
  interpolate in premultiplied space so it looks fine, but rgba(r,g,b,0) of the SAME colour is safest.

GRADIENT TEXT:
  background: linear-gradient(90deg, #ff5a5f, #1a73e8);
  -webkit-background-clip: text; background-clip: text; color: transparent;

INTERPOLATION COLOUR SPACE (new): linear-gradient(in oklch, blue, red)
  Smoother colours. Support: Chrome 111+, Safari 16.2+, Firefox 127+.

GRADIENTS CAN'T BE TRANSITIONED directly (it's an image): animate background-position/size,
  or register a variable with @property, or fade a pseudo-element's opacity.
```

## 🟡 Real World Example
**Instagram, Swiggy, Netflix:** The Instagram logo and story ring use a multi-stop gradient (yellow, orange, pink, purple). Swiggy and Zomato overlay a bottom `linear-gradient(transparent, rgba(0,0,0,.7))` on food photos so white text stays readable. Spotify and Gmail promo banners use diagonal gradient heroes. YouTube-style skeleton loading shimmer is a moving gradient (see topic 79), and dashboards draw donut charts with `conic-gradient`.

## ⚫ Interview Questions + Answers

**Q1: What types of CSS gradients exist and what are they used for?**
A1: `linear-gradient` (blends along a line/angle, for banners, buttons), `radial-gradient` (blends outward from a centre, for spotlights and glows), and `conic-gradient` (blends around a centre point, for pie charts and colour wheels). Each also has a `repeating-` variant for stripes and patterns.

**Q2: Is a gradient a colour or an image? What does that imply?**
A2: It is an `<image>` value, not a `<color>`. It can only be used where images are accepted: `background-image`, `border-image`, `list-style-image`, `mask-image`, `content`. It cannot be used in `background-color` or `color` directly (use `background-clip: text` for text). Because it is an image, it cannot be smoothly transitioned; animate `background-position` or `background-size` instead.

**Q3: How do you create a hard colour line (no blending) in a gradient?**
A3: Put two colour stops at the same position, for example `linear-gradient(90deg, red 50%, blue 50%)`. Same trick builds stripes, pie slices in `conic-gradient`, and progress bars.

**Q4: How do you put readable text on an image using gradients?**
A4: Layer a dark gradient over the image as multiple backgrounds: `background: linear-gradient(to top, rgba(0,0,0,.7), transparent), url(photo.jpg) center/cover;` The first listed layer is on top. This keeps the photo visible at the top and darkens the bottom for white text. Always still provide an `alt` or accessible name for meaningful photos.

**Q5: How do you create gradient text and a gradient border?**
A5: Text: set a gradient `background`, add `background-clip: text` (with `-webkit-` prefix for older Safari/Chrome) and `color: transparent`. Border: use `border: 4px solid transparent` with two backgrounds, `linear-gradient(#fff,#fff) padding-box, linear-gradient(...) border-box`. `border-image` also works but ignores `border-radius`.

## 🔷 Common Mistakes to Avoid

❌ **Mistake 1:** Using a gradient in `background-color`
```css
/* WRONG: invalid, ignored */
.hero { background-color: linear-gradient(red, blue); }

/* CORRECT */
.hero { background-image: linear-gradient(red, blue); }   /* or the background shorthand */
```

❌ **Mistake 2:** Expecting `transition: background` to animate a gradient
```css
/* WRONG: gradient jumps instantly */
.btn { background: linear-gradient(#f00, #00f); transition: background .3s; }
.btn:hover { background: linear-gradient(#0f0, #ff0); }

/* CORRECT: oversized background-size and move background-position */
.btn { background: linear-gradient(90deg, #f00, #00f, #0f0); background-size: 200% 100%; transition: background-position .4s; }
.btn:hover { background-position: 100% 0; }
```

❌ **Mistake 3:** Wrong angle direction expectations
```css
/* 0deg points UP, 90deg points RIGHT (compass style, clockwise). */
.a { background: linear-gradient(0deg, red, blue); }   /* red at bottom, blue at top */
```

❌ **Mistake 4:** Gradient text without a fallback / forgetting `color: transparent`
```css
/* WRONG: text colour hides the gradient */
.t { background: linear-gradient(90deg,#f00,#00f); background-clip: text; }

/* CORRECT */
.t { background: linear-gradient(90deg,#f00,#00f); -webkit-background-clip: text; background-clip: text; color: transparent; }
```

## ⚡ 3-Line Summary
**English:**
1. Gradients are browser-made images: `linear-gradient` (line), `radial-gradient` (centre outward), `conic-gradient` (around a point), each with colour stops.
2. Use them in `background-image`; same-position stops make hard edges, and multiple backgrounds make overlays and borders.
3. They cannot be directly transitioned; animate `background-position`/`size` instead.

**Hindi:**
1. Gradients browser की बनाई images हैं: `linear-gradient` (रेखा), `radial-gradient` (centre से बाहर), `conic-gradient` (centre के चारों ओर), colour stops के साथ।
2. `background-image` में use करो; एक ही position पर stops से सीधी रेखा बनती है, और multiple backgrounds से overlay व border बनते हैं।
3. इन्हें सीधे transition नहीं कर सकते; `background-position`/`size` animate करो।
