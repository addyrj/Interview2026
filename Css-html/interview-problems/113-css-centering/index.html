CSS Centering: 5 Different Ways

1. Flexbox

A
display:flex; justify-content:center; align-items:center

2. Grid place-items

B
display:grid; place-items:center

3. Absolute + transform

C
top:50%; left:50%; transform:translate(-50%,-50%)

4. inset:0 + margin:auto

D
position:absolute; inset:0; margin:auto; width/height fixed

5. text-align + line-height

E
text-align:center; line-height = height (single line only)
