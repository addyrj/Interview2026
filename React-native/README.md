## 📋 Android Publish Checklist
```
□ App icons (all sizes)          □ AAB file built
□ Splash screen                  □ Tested on real device
□ Keystore file saved safely     □ Tested multiple screen sizes
□ Bundle ID set correctly        □ No debug logs in release
□ Version code + version name    □ Release build tested
□ Permissions in manifest        □ Content rating completed
□ Privacy policy URL             □ Store listing ready
□ Screenshots (phone + tablet)
```

## 📋 iOS Publish Checklist
```
□ Apple Developer Account ($99)  □ IPA built successfully
□ Bundle ID registered           □ Tested on TestFlight
□ Certificates created           □ Tested on real iPhone/iPad
□ Provisioning profiles setup    □ No debug code in release
□ App icons (all sizes)          □ App description ready
□ Splash screen                  □ Screenshots all device sizes
□ Info.plist permissions         □ Age rating completed
□ Privacy policy URL             □ App preview video (optional)
```
