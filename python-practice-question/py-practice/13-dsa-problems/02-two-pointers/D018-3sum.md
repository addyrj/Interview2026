# D018. 3Sum
# Category: DSA — Two Pointers
# Difficulty: ⭐⭐ Medium | LeetCode #15

---

## ❓ Problem
Given an integer array `nums`, return all **unique** triplets `[a, b, c]` such that `a + b + c == 0`.

```
Input:  nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
```

---

## 💡 Quick Concept (2 lines only)
Sort the array, fix one number `a`, then solve Two Sum (two pointers) on the rest for `-a`. Skip duplicate values for `a`, `b` and `c` to avoid repeated triplets.
हिंदी: Sort करो, एक number fix करो, बाकी में two pointers से Two Sum हल करो; duplicates skip करना मत भूलो।

---

## ✅ Solution

```python
# ============================================
# APPROACH 1: Brute force — all triples + set to dedupe
# O(n^3) time, O(k) space
# ============================================
def three_sum_brute(nums: list[int]) -> list[list[int]]:
    n = len(nums)  # array length
    found: set[tuple[int, int, int]] = set()  # unique sorted triplets
    for i in range(n):  # first element
        for j in range(i + 1, n):  # second element
            for k in range(j + 1, n):  # third element
                if nums[i] + nums[j] + nums[k] == 0:  # triplet sums to zero
                    found.add(tuple(sorted((nums[i], nums[j], nums[k]))))  # store canonical form
    return sorted([list(t) for t in found])  # deterministic output order

# ============================================
# APPROACH 2: Sort + two pointers — O(n^2) time, O(1) extra space ✅ PREFERRED
# ============================================
def three_sum(nums: list[int]) -> list[list[int]]:
    nums = sorted(nums)  # sort a copy (needed for two pointers)
    res: list[list[int]] = []  # collected triplets
    n = len(nums)  # array length
    for i in range(n - 2):  # fix the smallest element
        if nums[i] > 0:  # smallest is positive -> sum can never be 0
            break  # stop early
        if i > 0 and nums[i] == nums[i - 1]:  # same value as previous fixed element
            continue  # skip duplicate
        l, r = i + 1, n - 1  # two pointers over the rest
        while l < r:  # search the pair
            s = nums[i] + nums[l] + nums[r]  # current sum
            if s < 0:  # too small
                l += 1  # need a larger value
            elif s > 0:  # too big
                r -= 1  # need a smaller value
            else:  # found a triplet
                res.append([nums[i], nums[l], nums[r]])  # record it
                l += 1  # move left inward
                r -= 1  # move right inward
                while l < r and nums[l] == nums[l - 1]:  # skip duplicate left values
                    l += 1  # advance past duplicates
                while l < r and nums[r] == nums[r + 1]:  # skip duplicate right values
                    r -= 1  # retreat past duplicates
    return res  # all unique triplets

# ============================================
# TEST CASES
# ============================================
print(three_sum_brute([-1, 0, 1, 2, -1, -4]))  # [[-1, -1, 2], [-1, 0, 1]]
print(three_sum([-1, 0, 1, 2, -1, -4]))  # [[-1, -1, 2], [-1, 0, 1]]
print(three_sum([0, 1, 1]))  # []
print(three_sum([0, 0, 0, 0]))  # [[0, 0, 0]]
print(three_sum([]))  # []
print(three_sum([-2, 0, 0, 2, 2]))  # [[-2, 0, 2]]
```

---

## 🔍 Why It Works
```
sorted: [-4, -1, -1, 0, 1, 2]
i=-4: pair needs 4 -> none
i=-1 (idx1): l=-1, r=2 -> sum 0 -> [-1,-1,2]; then 0+1 -> [-1,0,1]
i=-1 (idx2): same as previous -> skipped
```
हिंदी: Sorting से duplicates पास-पास आ जाते हैं और two pointers से हर fixed element के लिए O(n) में pair मिल जाता है → कुल O(n²)।

---

## 📊 Complexity
```
Brute force: Time O(n^3)  | Space O(k)
Sort + 2ptr: Time O(n^2)  | Space O(1) extra (ignoring output/sort) ← preferred
```

## ⚡ Variations

```python
# VARIANT 1: Hash-set version for the inner pair (still O(n^2))
def three_sum_hash(nums: list[int]) -> list[list[int]]:
    nums = sorted(nums)  # sort so triplets come out canonical
    res: set[tuple[int, int, int]] = set()  # unique triplets
    for i in range(len(nums) - 2):  # fix first element
        seen: set[int] = set()  # values seen for the inner pair
        for j in range(i + 1, len(nums)):  # scan the rest
            need = -nums[i] - nums[j]  # third value required
            if need in seen:  # complement seen earlier
                res.add((nums[i], need, nums[j]))  # sorted order is preserved
            seen.add(nums[j])  # remember this value
    return sorted([list(t) for t in res])  # deterministic output

print(three_sum_hash([-1, 0, 1, 2, -1, -4]))  # [[-1, -1, 2], [-1, 0, 1]]
print(three_sum_hash([0, 0, 0, 0]))  # [[0, 0, 0]]
# VARIANT 2: 3Sum Closest — same pattern, track the sum closest to target
# VARIANT 3: 4Sum — add one more outer loop, still two pointers inside
```
